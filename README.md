# Tani Shopping Automat

**Wersja:** 1.0.0

**Przeznaczenie:** Wewnętrzna aplikacja do automatyzacji obsługi zamówień sklepu Tani Shopping na platformie Allegro.

## Planowane funkcje
- Pobieranie zamówień przez Allegro REST API.
- Sprawdzanie statusów zamówień.
- Obsługa wiadomości do klientów w zakresie dozwolonym przez Allegro.
- Rejestrowanie wysłanych wiadomości, aby zapobiegać duplikatom.
- Automatyczne działanie na serwerze 24/7.

## Bezpieczeństwo
- Autoryzacja za pomocą OAuth 2.0.
- Bezpieczne przechowywanie tokenów.
- Dostęp wyłącznie dla właściciela aplikacji.

**Status:** Projekt w trakcie wdrażania.
